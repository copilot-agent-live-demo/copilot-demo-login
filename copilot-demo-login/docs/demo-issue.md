# 로그인 실패 시 에러 메시지가 표시되지 않음

<!-- 아래부터 이슈 본문에 그대로 붙여넣기 -->
## 배경

로그인에 실패해도 화면에 아무 안내가 없어서, 사용자는 버튼이 고장 난 줄 압니다.
현재는 `src/LoginForm.ts`에서 오류를 `console.error`로만 남기고 있습니다.

## 할 일

- LoginForm에 오류 메시지 표시 영역 추가
- 실패 유형(`AuthError.code`)별로 메시지 분기
  - `INVALID_CREDENTIALS`: 이메일 또는 비밀번호가 올바르지 않습니다.
  - `ACCOUNT_LOCKED`: 계정이 잠겼습니다. 관리자에게 문의해 주세요.
  - `NETWORK_ERROR`: 네트워크 연결을 확인한 뒤 다시 시도해 주세요.
  - 그 외: 알 수 없는 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.
- 다시 로그인을 시도하면 이전 오류 메시지는 지우기

## 완료 조건

- 유닛 테스트 통과 (실패 유형별 메시지 테스트 추가)
- 스크린리더 접근성 유지 (오류 메시지는 `role="alert"`로 읽힘)
- `src/api/`는 수정하지 않음
