# 다크 모드 지원

<!-- 아래부터 이슈 본문에 그대로 붙여넣기 -->
## 배경

OS를 다크 모드로 쓰는 사용자에게도 로그인 화면이 흰 배경으로 보여 눈이 부십니다.

## 할 일

- `src/dark.css` 새 파일에 `@media (prefers-color-scheme: dark)` 스타일 작성
  - 페이지 배경, 로그인 카드, 입력란, 글자 색을 어두운 테마에 맞게 변경
  - 로그인 버튼의 보라색 계열과 환영 메시지의 초록색 계열은 유지하되 어두운 배경에서 잘 보이게 조정
- `index.html`에서 `style.css` 다음 줄에 `dark.css` 링크 추가

## 완료 조건

- **`src/style.css`는 수정하지 않음** (다크 모드 스타일은 `dark.css`에만 작성)
- 다크 모드에서 글자와 배경의 명도 대비가 WCAG AA(4.5:1) 이상
- 타입 검사와 기존 테스트 통과
