# VS Code Agent Mode 시연용 프롬프트

클라우드 에이전트가 이슈를 처리하는 동안, VS Code에서 보여줄 작은 작업입니다.
copilot-instructions.md의 규칙(순수 DOM, 한국어 존댓말, 테스트 추가)이 자동으로 반영되는지 보는 것이 포인트입니다.

## 프롬프트 (Agent Mode에 붙여넣기)

```
로그인 폼의 비밀번호 입력란 옆에 "비밀번호 보기" 토글 버튼을 추가해줘.
누르면 비밀번호가 보이고, 다시 누르면 가려지게.
```

## 확인할 것

- 프롬프트에 적지 않았는데도 지켜지는 규칙
  - 라이브러리 없이 DOM API로 구현했는가
  - 버튼 문구가 한국어인가 ("비밀번호 보기" / "비밀번호 숨기기")
  - `LoginForm.test.ts`에 테스트를 추가했는가
- 접근성: 토글 버튼에 `aria-pressed` 또는 상태를 알리는 라벨이 있는가

시연이 끝나면 변경 사항은 취소(Undo)하거나 커밋하지 않고 버립니다.
